# SQL Studies

Este repositório foi criado com o objetivo de compartilhar os meus estudos em SQL, que estou realizando através do curso de Administração de Bancos de dados do Instituto Federal do Rio Grande do Sul campus Veranópolis, realizada em formato EaD. A ideia é que este repositório possa contribuir para que pessoas interessadas nesta linguagem também usufruem do material que preparo durante o curso para aprendizado e prática.

Este curso aborda aspectos teóricos sobre criação e administração de bancos de dados, e também aborda a linguagem SQL (_Structured Query Language_), a linguagem mais utilizada para manejar dados em banco de dados relacionais. O curso também possui uma parte prática bem robusta, abordando o uso dos dois software livre de Sistema Gerenciador de Banco de Dados (SGBD) mais utilizados: PostregreSQL e MySQL. 

Aqui, abordo principalmente os aspectos práticos do uso do SQL para criação, manutenção e extração de dados de Banco de Dados relacionais.
