# SQL Studies

Este repositório foi criado com o objetivo de compartilhar os meus estudos em SQL, que estou realizando desde Julho de 2026 através do curso de Administração de Bancos de dados do Instituto Federal do Rio Grande do Sul campus Veranópolis. A ideia é que este repositório possa contribuir para que pessoas interessadas em aprender SQL possam utilizar esse material que tenho preparado através das minhas anotações.

Este curso aborda aspectos teóricos sobre criação e administração de bancos de dados, e também aborda a linguagem SQL (_Structured Query Language_), a linguagem mais utilizada para manipular dados em banco de dados relacionais. O curso também possui uma parte prática bem robusta, abordando o uso dos dois software livre de Sistema Gerenciador de Banco de Dados (SGBD) mais utilizados: PostgreSQL e MySQL. 

Aqui, abordo principalmente os aspectos práticos do uso do SQL para criação, manutenção e extração de dados de Banco de Dados relacionais.
Até o momento, finalizei as práticas com o PostgreSQL, e irei iniciar com o MySQL.
